# tgbot
# 📚 Telegram Bot for Online School

Интерактивный Telegram-бот для онлайн-школы, разработанный на **Python Kodland** 

Бот позволяет:
- просматривать курсы
- записываться на обучение
- смотреть расписание
- получать автоматические уведомления о занятиях



## 🚀 Функционал

-  Приветственное сообщение (/start)
-  Кнопочное меню
-  Просмотр доступных курсов
-  Запись на курс (пошаговый диалог)
-  Просмотр расписания занятий
-  Автоматические уведомления перед занятием
-  Раздел помощи
